🦠 COVID-19 Live Statistics App
A responsive and modern web application built using HTML, CSS, Bootstrap, and JavaScript to display real-time global COVID-19 statistics. Data is fetched from a public API using the Fetch API. The site includes sections like About, Symptoms, Global Data, and a Footer with contact info.

🌐 Live Preview
👉 https://covid-19-api-app.vercel.app/

🚀 Features
📊 Live COVID-19 global data: Confirmed cases, Deaths, and Active cases

🎨 Clean and modern UI using Bootstrap 5

📱 Fully responsive design for all screen sizes

📌 Informative sections including About, Symptoms, and Preventive Measures

🌍 Footer with regions, services, and contact info

🔁 Real-time data fetch using RapidAPI

Source: COVID-19 Statistics API on RapidAPI

To use your own API key, replace the X-RapidAPI-Key value inside script.js.

🔐 Note on API Key
The API key used in this project is public for demonstration. It's recommended to register your own RapidAPI key for production use.
